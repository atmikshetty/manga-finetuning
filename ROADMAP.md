# Roadmap

## 0.1

- Validate core image and caption transforms with generated fixtures.
- Provide portable epsilon and v-prediction Kohya wrappers.
- Publish lawful-data and artifact-provenance guidance.

## Later

- Add scalable perceptual-hash indexing for very large lawful datasets.
- Support user-supplied panel detector adapters without expanding core deps.
- Add optional evaluation reports for human rankings and memorization review.
- Establish reproducible release artifacts and compatibility matrices.

Acquisition, scraping, raw datasets, generation apps, page composition, and
artifact hosting remain explicitly out of scope.
