# Support

Use GitHub Discussions for setup and workflow questions and GitHub Issues for
reproducible defects. Include operating system, Python version, sanitized
command, pinned dependency revisions, and the smallest generated fixture.

Do not share credentials, private paths, private data, scans, model weights, or
provider identifiers. Security reports follow [SECURITY.md](SECURITY.md).
Maintainers cannot provide legal advice or determine whether you hold rights to
a dataset.
