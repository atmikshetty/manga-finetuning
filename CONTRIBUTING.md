# Contributing

Contributions are welcome when they remain within the curated scope and can be
tested without proprietary artifacts.

1. Open an issue for behavior changes or new dependencies.
2. Create a focused branch and add tests using generated fixtures.
3. Run `pytest`, `ruff check .`, `ruff format --check .`, and shell syntax checks.
4. Use conventional commits and sign off if your organization requires it.
5. Document data-governance or reproducibility implications.

Do not submit scans, artwork, datasets, weights, credentials, personal paths,
provider identifiers, or generated galleries. By contributing, you represent
that you may license your contribution under Apache-2.0.
