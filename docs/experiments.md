# Sanitized Experiment Records

The migration retained only factual, generalizable observations from prior
development; no prompts naming copyrighted series, personal paths, provider
identifiers, source images, or result galleries are included.

- Whole pages encourage layout learning; isolated panels better target drawing
  characteristics when page composition is outside model scope.
- Text boxes should be removed before training to reduce malformed text output.
- Intermediate checkpoints can outperform final saves on prompt adherence.
- Small character datasets overfit pose and framing unless variable camera
  attributes are captioned.
- V-prediction base checkpoints need matching training and inference scheduler
  semantics, including zero-terminal-SNR handling.
- Scalar frequency or variance heuristics can misclassify valid dense line art;
  checkpoint choice remains a structured human evaluation.
