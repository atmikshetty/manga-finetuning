# Dataset Publishing

Do not publish a dataset merely because the pipeline can create it. Verify that
the source license or written permission allows redistribution and ML use of
both originals and transformed panels. Cropping and whiteout do not create new
distribution rights.

Complete the dataset-card template with provenance, rights holder, license,
version, transformations, exclusions, sensitive-content review, takedown
contact, splits, counts, checksums, and known limitations. Remove personal
paths and embedded metadata. Use an immutable manifest and test downloads.

If redistribution is prohibited, publish only code, schemas, aggregate factual
statistics that do not reconstruct the work, and instructions for authorized
users to process their own lawful copies.
