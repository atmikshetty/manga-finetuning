# Data Governance

Maintain an inventory for every dataset version with owner, custodian, origin,
acquisition date, lawful basis, license or permission, allowed purposes,
territory, retention period, deletion process, and downstream restrictions.

Keep source data access-controlled and separate from this repository. Give
derived panel datasets their own immutable version and manifest; transformation
does not erase source obligations. Record exclusions and honor withdrawal or
deletion requests through all derivatives and pending releases.

Review datasets for personal information, minors, sensitive material,
watermarks, signatures, and unwanted text. Restrict access by least privilege.
Never place source or derived artwork in issue attachments or CI artifacts.
